## What's new in v1.15

**Smart albums (saved views)**
- Save whatever you are looking at (search words, sidebar view, type, and all the detail filters) as a named smart album. Use Save view… in the side panel, Ctrl+S, or right-click in the sidebar
- Smart albums sit in the sidebar with a ◆ and a live image count, and they keep themselves up to date as images are added, tagged or changed. Clicking one applies it, including opening the filter bar when it uses filters
- Right-click one to see what it matches, replace it with the current view, rename it, reorder it or delete it. Deleting a smart album never touches images

**Tag manager** (Manage tags… in the side panel, Ctrl+T, or right-click a tag)
- A table of every tag with its image count, sortable and filterable
- Rename a tag, merge several tags into one (for example cat and cats), or delete tags from every image
- Big changes (10 or more images) get a restore point so they can be undone. Smart albums and the current view follow a renamed or merged tag

**Fixes and tidying**
- Typing nan or inf into a filter box no longer causes an error
- Dark mode styling for the new tag table

Existing libraries upgrade automatically on first launch.

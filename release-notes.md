## What's new in v1.14

**Keyboard shortcuts** (press F1 or the ? button for the full list)
- Arrow keys move the selection, Page Up / Page Down change page, Home / End jump to the first or last image on the page
- Enter opens the full-size viewer, Esc clears the selection, Ctrl+A selects the page
- 0 to 5 rate the selected images and F toggles favourite
- Delete moves the selected images to the app trash, and Restore points can undo it
- F5 refreshes, Ctrl+F jumps to search, Ctrl+O adds a folder, Ctrl+Shift+F shows the filters
- Shortcuts step aside while you are typing in a box or using a dropdown or list

**Search by details**
- New Filters button with a bar for: shape (landscape, portrait or square), minimum width and height in pixels, file size range in MB, taken date range (a year, a month or a full date) and format (PNG, JPG, WEBP, GIF)
- Filters combine with the search box, sidebar views and albums, and with everything that works on "what is showing" (sort, rename, mark type)
- Image sizes are recorded when images are added. For images already in your library they are read once in the background after you update, with progress in the status line

Existing libraries upgrade automatically on first launch.

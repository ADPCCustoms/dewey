## What's new in v1.13

- The app now has a name: Dewey. The window title and the exe (Dewey.exe) use it, and the README is updated to match
- No other changes to features or to your library

**Updating from ImageLibrary.exe:** Dewey keeps its library next to the exe. Put Dewey.exe in the same folder as your existing `library.db` (and the `restore` and `thumbs` folders, if present) so it opens your existing library. Otherwise it starts with an empty one. You can then delete the old ImageLibrary.exe.
